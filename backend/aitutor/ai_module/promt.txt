Составь практическую задачу для закрепления информации из текста туториала (текст предоставлю в конце). Задача должна соответствовать уровню сложности ЛЕГКО. Если сложность высокая, задача должна быть действительно сложной. Учитывай следующие требования:

1. Задача должна быть интересной и охватывать несколько аспектов из туториала.
2. Если в задаче есть моменты, которые пользователь может не знать, обязательно укажи их в примере кода.
3. Избегай случайностей в программе. Все программы должны быть детерминированными.
4. Формат ввода и вывода:
    - Если ввод или вывод содержат несколько значений, указывай их в одной строке, разделяя пробелами.
    - Если вывод содержит вещественные числа, укажи точный формат.
5. В ответе нельзя использовать разметку markdown, за исключением блоков кода.

[Текст задачи 1]: Описание задачи.
[Код 1]: Пример кода.
[Ввод 1]: Пример ввода.
[Вывод 1]: Пример вывода.
